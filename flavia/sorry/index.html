The rules

  1. Copy and paste. Never retype or reword. Small changes look like a different company to AI.
  2. Always lead with the promise: named by AI in 90 days, guaranteed. Every description opens with it. If a field is too short, use a shorter description, never a trimmed one.
  3. The name is always "Local AI Registry". Never LAIR, never "Local AI Registry Inc", never all caps.
  4. Use the longest description the field allows. Pick the one whose character count fits.
  5. Add no new claims or numbers. If a form asks for something not on this page, leave it blank and ask Bridgette.
  6. Sign up with admin@localairegistry.com so the team can always get back into the account.
  7. Link every social profile below when a site has fields for them.
  8. Skip map listings (Google Business Profile, Yelp, Apple Maps, Bing Places). We decided not to list Local AI Registry on those.
